# Color Ripples
Updated 5/1/25
The first web app I built back in 2022! A simple and unique puzzle game that requires players to think differently. The game was playable on my website until 2023 when Ben Mountain and I turned it into a React Native app and released it on the Apple Store. 

For an idea of what the game looked like on my website you can explore a code pen, which includes the custom page template and CSS, along with an early version of the code (much more buggy than the app!).
Code pen: https://codepen.io/Dillon-Lanier/pen/dPPJEga
